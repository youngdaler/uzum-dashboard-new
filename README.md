# Uzum Business Dashboard

Учёт бизнеса «закупка в Китае → продажа на Uzum Market»: партии закупок и полная себестоимость, склад (средневзвешенная или FIFO), продажи с удержаниями Uzum, возвраты, расходы, финансы (выручка / прибыль / денежный поток / задолженности раздельно), аналитика, калькулятор и оценка закупки.

Стек: React + Vite + TypeScript, Tailwind CSS 4, Radix-компоненты в стиле shadcn/ui, Recharts, React Hook Form + Zod, date-fns, decimal.js, Supabase.

## Быстрый старт (без сервера)

```bash
npm install
npm run dev        # http://localhost:5173
```

Без настройки Supabase приложение работает в **локальном режиме**: данные сохраняются в localStorage браузера. Откройте «Настройки → Данные → Загрузить демо-данные», чтобы увидеть работу расчётов; демо удаляется одной кнопкой. Делайте резервные копии (Настройки → Данные → JSON).

## Подключение Supabase (хранение в облаке, вход по email)

1. Создайте проект на supabase.com.
2. В SQL Editor выполните `supabase/migrations/0001_schema.sql` (таблицы, ограничения, индексы, Row Level Security — каждый пользователь видит только свои данные).
3. Создайте `.env` в корне:
   ```
   VITE_SUPABASE_URL=https://<project>.supabase.co
   VITE_SUPABASE_ANON_KEY=<anon key>
   ```
4. `npm run dev` — появится экран входа/регистрации.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер |
| `npm run build` | проверка типов + production-сборка в `dist/` |
| `npm test` | тесты формул (себестоимость, распределение расходов, склад, прибыль) |
| `npm run lint` | oxlint |

## Важное

- Тарифы Uzum **не зашиты**: вводятся в «Настройки → Тарифы Uzum» и хранятся с историей (действуют с даты).
- Курсы CNY/USD вводятся вручную; в каждой партии и расходе сохраняется курс на дату операции.
- Деньги считаются через `decimal.js`, хранятся как `numeric`.
- Налоговую ставку укажите сами (Настройки → Расчёты и налоги).
- Прибыль считается по проданным единицам; непроданный товар остаётся в запасах, закупка не вычитается повторно.
